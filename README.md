# Alternative Learning System (ALS) Mobile Learning Management System

A full-featured Android Learning Management System (LMS) designed specifically for the Alternative Learning System (ALS) framework. Built natively using Android Studio with Kotlin/Java and powered by a real-time Firebase backend.

## 📱 Key Features

- **Role-Based Access Control:** Distinct workflows, dashboards, and restricted views for Administrators (Teachers/Coordinators) and Students.
- **Dynamic Enrollment Engine:** Custom workflow allowing administrators to review, accept, or decline pending student registration applications.
- **Academic Suite:** Centralized teacher controls to create, publish, and track progress for learning modules, interactive quizzes, activities, and announcements.
- **In-App Communication:** Native real-time chat module connecting administrators and students directly for immediate academic support.
- **Cloud Architecture:** Fully integrated with Firebase for reliable data management, real-time sync, and user authentication.

## 🛠️ Tech Stack

- **Frontend:** Android Studio (Java / Kotlin), XML Layouts
- **Backend & Database:** Firebase Authentication, Cloud Firestore / Realtime Database
- **Architecture Patterns:** MVVM (Model-View-ViewModel), Repository Pattern
